# Alok Chauhan · Portfolio

Personal portfolio of Alok Chauhan, a first-year Computer Science student at Newton School of Technology, Pune.

A single-page site with a liquid-glass look and interactive sections:

- 3D liquid glass object (Three.js) that drifts and zooms as you scroll
- Robotic arm that picks up words and assembles a sentence
- Playable chess board where each white pawn reveals a word
- Auto-playing basketball game where each basket drops a word
- Scratch-to-reveal panels, a robot guide, floating emojis, and a scroll-drawn timeline
- Light and dark themes

## Run it

It's one file. Open `index.html` in a browser, or enable GitHub Pages on the `main` branch.

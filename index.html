Hacktober HackDay · NST PunePython · MIT

Bug Slayer

A CLI that tests whether a project's setup instructions actually work. It runs every README step in a Docker sandbox, asks Gemma to diagnose the failures, and patches the broken lines.

README as written$ pip install -r requirments.txt
ERROR: Could not open requirements file
$ python app.py
ModuleNotFoundError: No module named 'rich'
$ cp .env.example .env
✗ 0/3 steps passed
After Bug Slayer$ pip install -r requirements.txt   ✓
$ pip install rich                  ✓
$ python3 -m app                    ✓
$ cp .env.example .env              ✓
✓ README patched · patch file ready
HealerRuns an existing README, diagnoses failed steps and rewrites them.
